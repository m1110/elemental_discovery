How a new element gets made, and proven

An element is defined by one number: how many protons sit in its nucleus, its . The periodic table currently ends at oganesson, Z = 118. Nothing heavier exists in nature, so every new element has to be built by hand, one atom at a time.

The recipe is to fire a beam of medium-weight nuclei (titanium, chromium) at a target made of a heavy, rare element (curium, californium) so that the two fuse. Making a single atom can take weeks of beam, and the atom then lives for millionths of a second.

Nobody sees the new atom directly. What a detector sees is the atom's , one after another, until the chain reaches a nucleus scientists have already seen before. That link to known territory is the proof. This page predicts how long each unknown nucleus lives, whether its chain reaches known ground, and how likely a real experiment is to succeed.

Half-lives decide everything

The is the time for half of a sample to decay. If it is shorter than the ~1 µs an atom needs to fly to the detector, the atom is lost. If the nucleus instead of alpha-decaying, its chain breaks before reaching known nuclei.

The island of stability

Nuclei with certain "" numbers of protons or neutrons are extra stable. Theory predicts an island of longer-lived superheavy nuclei near 184 neutrons, but no one agrees on its magic proton number (114, 120 or 126), so this page shows all three.

Odds, not certainties

Every prediction is an extrapolation into unexplored territory, so each comes with an error bar. The planner folds every uncertainty into one honest number: the chance that a real experiment succeeds.

How the model works

Four steps, each one a physics law fitted to measured data. Open "Show the maths" for the equations and how each step was checked.

Weigh the nucleus

How tightly a nucleus is bound sets how much energy it releases when it decays (its ). The model treats the nucleus as a charged liquid drop, then adds a correction for : the extra stability near magic numbers. It is fitted to 463 measured alpha decays.

Show the maths
B(Z,N) = a_v A − a_s A^(2/3) − a_c Z(Z−1)/A^(1/3) − a_sym (N−Z)²/A + … − E_shell(Z,N) Q_α = B(daughter) + B(⁴He) − B(parent)

A Gaussian-process correction pulls predictions onto nearby measurements. Its error bar then grows with the distance d from the nearest measured nucleus, σ² = σ_GP² + (k·d)², with k fitted so that predictions for unseen heavier nuclei have honest error bars.

Turn energy into a lifetime

An alpha particle escapes by quantum tunnelling through the nucleus's electric barrier, so more energy means a much shorter life. Fission competes, and shell effects hold it back. Both laws are fitted to measured half-lives.

Show the maths
log₁₀ T_α = a·χ + b·ρ + c + h·[odd] χ = Z_α Z_d √(A_red/Q), ρ = √(A_red Z_α Z_d (A_d^⅓ + A_α^⅓)) log₁₀ T_SF = s₀ + s₁u + s₂u² + k·(−E_shell) + h_f·n_odd, u = Z²/A − 37.5

The alpha law is the WKB tunnelling exponent with four fitted constants. It replaced a six-parameter formula because it predicts unseen nuclei better. Each law reports its predictive error σ² = s² + xᵀCx, which grows automatically when it extrapolates.

Learn from past experiments

How often a beam and target fuse into a surviving atom (the ) falls steeply as the nuclei get heavier. The trend is fitted to every successful experiment and also to the searches that found nothing, which are real evidence too.

Show the maths
log₁₀ σ = c₀ + c₁·x_m + ε, ε ~ Normal(0, s²) a 90% upper limit σ_lim means exposure L = ln 10 / σ_lim P(0 events) = E[ exp(−L·σ) ]

A failed search is a count of zero over a known exposure, so it enters the fit through the Poisson probability of seeing nothing. A reaction that was already tried updates its own estimate downwards, exactly once.

Combine into one chance of success

An experiment succeeds if it records enough decay chains that each reach a known nucleus. That needs a big enough cross section, atoms that survive the flight to the detector, and chains that alpha-decay all the way down.

Show the maths
P(discovery in D days) = P_anchor · E[ P_Poisson(≥ k ; λ·D) ] λ = σ · beam · target · efficiency · 2^(−t_flight / T) P_anchor = Π over new links of P(alpha beats fission)

The average runs over the uncertain cross section and half-life, using Gauss–Hermite quadrature. Your browser runs this calculation live as you move the planner's sliders.

How much to trust it

Each law was put through a : fitted on lighter nuclei, then asked to predict heavier ones it had not seen, the way the elements were actually discovered. A model that passes this test has earned its error bars.

Getting into this work

Superheavy-element research mixes accelerator experiments, nuclear theory, statistics and chemistry. You can contribute from any of these directions.

Where it happens

  • JINR Flerov Laboratory, Dubna (Russia), where elements 114–118 were first made
  • GSI / FAIR, Darmstadt (Germany), home of the 119 and 120 searches with TASCA and SHIP
  • RIKEN Nishina Center (Japan), which discovered nihonium
  • Lawrence Berkeley National Laboratory (USA), which made livermorium with a titanium beam in 2024

Useful background

  • Nuclear physics: the liquid-drop model, shell structure, quantum tunnelling
  • Statistics: Poisson counting, likelihoods, honest error bars
  • Programming: Python and NumPy are enough to read every line of this model
  • Chemistry, if you want to test where a new element sits in the periodic table

The data behind it

  • NUBASE2020: half-lives, decay modes and masses for every known nucleus (Kondev et al., 2021)
  • AME2020: the atomic mass evaluation, including Q-values
  • ENSDF: the IAEA's detailed nuclear structure files
  • The original discovery papers for cross sections and null searches

Open problems to try

  • Find a fission law that predicts unseen nuclei well (the best is still ±2.4 decades)
  • Add Q-values for odd nuclei directly from AME2020
  • Sum over neighbouring evaporation channels (3n and 4n) instead of picking one
  • Model the correlation between a residue's half-life and its chain's survival

Run it yourself

  • pip install -r requirements.txt
  • python -m elemental_discovery discover 120
  • python -m pytest -q runs the checks against known physics
  • python tools/build_ui.py rebuilds this page

All of it lives in the elemental_discovery repository: docs/REPORT.md has every result and docs/AUDIT.md explains each modelling choice.
